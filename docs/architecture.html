gamekit Architecture

A game-agnostic toolkit shared by truco-py and catan. It has a stdlib-only core and two independent stacks on top: seat-rotated evaluation (benchmark, league, statistics) and single-agent RL plumbing. No module imports a game engine. Games plug in through Protocols and plain callables.

What each module does

core · stdlib

agent
The Agent[StateT, ActionT] Protocol: name, choose_action, reset. It is the only top-level re-export.
seats
BLAKE2b-seeded per-seat RNG (seat_rng, plus the frozen seat_rng_legacy), rotate, and seat_occupancy_counts.
results
stamp adds the git commit and UTC timestamp to a payload; write_result writes it as JSON.

mc · stdlib

mc.intervals
wilson_interval, ConfidenceInterval, and MCResult with a normal CI.
mc.testing
two_proportion_test (z, p) and benjamini_hochberg.
mc.sample_size
CLT, Hoeffding and two-proportion sample-size formulas.
mc.accumulate
The Accumulator[V, S, R] Protocol and MeanAccumulator.
mc.sample
The Sampler → Evaluator → Accumulator fold: monte_carlo and monte_carlo_reduce, with Welford state.
mc.stopping
monte_carlo_until runs the fold in chunks until it reaches a target CI half-width or a hard cap.
mc.variance
Antithetic sampling, paired_mean, control_variate and control_beta.

evaluation · stdlib

benchmark
run_arm plays one role lineup with mandatory seat rotation and reports win rates by role and by seat with Wilson CIs, plus a two-proportion test. Also provides the build_parser CLI skeleton.
league.round_robin
run_league calls run_arm once per pair. Results resume one pairing at a time, checked by config hash. summarize_league recomputes everything from disk.
league.ratings
A Bradley-Terry MLE (Hunter MM with a prior_draws prior), anchored onto the Elo scale, with bootstrap CIs, a win matrix and find_cycles.

rl · stdlib except env

rl.protocols
TurnBasedGame, ActionCodec and RewardFn: the seams a game adapts to.
rl.driver
advance_until_learner steps every seat whose agent is not None until the learner must act.
rl.masking
legal_action_mask (returns list[bool]) and coerce_to_legal (an illegal index becomes a random legal one).
rl.selfplay
OpponentPool globs a run-scoped checkpoint directory and mixes in a baseline agent.
rl.env
SingleAgentEnv is a gymnasium env for flat, masked-Discrete games. It is the only module that needs gymnasium and numpy.

Data flow A: benchmark and league

game supplies

Names + callables

Agent or role names, num_seats, a play callable and a winning_seat accessor.

league.round_robin

Schedule pairings

For each sorted pair (a, b), the lineup is (a, b, a, b, …); odd seat counts raise. Seeds come from a BLAKE2b hash of (seed, a, b), so adding an agent leaves existing pairings unchanged. Pairings already on disk with a matching config hash are skipped.

benchmark.run_arm

Seeds + rotation

n_games consecutive (engine_seed, driver_seed) pairs, with the lineup rotated by rotation_offset(engine_seed) % k. n_games must be a multiple of k.

game plays

Seeded games

From run_arm, play gets only seed pairs and recomputes the rotation with seats.rotate. From run_league, it gets ScheduledGames with the lineup already rotated.

benchmark → mc

Win rates + CIs

Results go through winning_seat, then into by_role and by_seat with Wilson CIs. A two-proportion z-test runs when there are 2 roles. A post-check raises ValueError if seat occupancy is unbalanced. The payload is stamped.

league.ratings

Ratings + matrix

Each pairing is written to .partial, then moved into place with os.replace. Then: Bradley-Terry fit → Elo anchored on one agent → bootstrap CIs → win_matrix (Wilson CI and residual against BT) → find_cycles. Output goes to league.json.

Ties (where winning_seat returns None) are left out of the rating fit and reported per pairing. The "Elo" values are a batch Bradley-Terry MLE expressed on the Elo scale, not online Elo updates. summarize_league needs only the stored pairings, so you can refit with a different anchor or prior without replaying any games.

Data flow B: RL self-play

game supplies

Adapter + codec

A TurnBasedGame adapter, an ActionCodec, encode, a RewardFn and an observation space.

SingleAgentEnv.reset

Seat the episode

Reseed, then pick the learner's seat. Fill the other seats from OpponentPool.seat_agents (or a fixed list) and call reset() on each agent. Deal with game.reset(seed), call on_episode_start, and advance. A game that ends before the learner acts is re-dealt. This draw order is part of the contract.

step(action)

Masked move

legal_action_mask builds the mask. An illegal index is coerced to a legal one (or raises). Then codec.from_index → apply_action → advance_until_learner → reward.compute. action_masks() exposes the mask to sb3-contrib.

caller's trainer · outside gamekit

Write checkpoints

The trainer (sb3-contrib in truco-py) saves models to pool.checkpoint_dir, which is directory/run_id.

rl.selfplay

Resample opponents

OpponentPool.sample re-globs the directory. With probability 1 − baseline_mix (default 0.2 mix) it returns load_opponent(path); otherwise baseline_factory(). With no checkpoints yet it always returns the baseline. The result feeds the next reset.

The loop closes outside the library. gamekit only reads checkpoint paths and calls the loader you inject. It never imports torch or stable-baselines3. Games with spatial or variable action spaces skip SingleAgentEnv and build their own gym.Env from protocols, driver and selfplay.

Where the games hook in

truco-py

depends on gamekit[rl] · 6 players, 2 teams
  • agents/base.py re-exports Agent.
  • training/env.py: TrucoEnv subclasses SingleAgentEnv, with _GameAdapter (TurnBasedGame) and _ActionCodec. It overrides on_episode_start to compute an MC win-probability estimate.
  • training/pool.py: TeamOpponentPool subclasses OpponentPool to sample opponents per team.
  • scripts/benchmark.py, training/eval.py: run_arm with num_seats=2 (one seat per team), plus rotate.
  • scripts/league_010.py: run_league and summarize_league.
  • engine/truco.py, experimentos/*, scripts/analyze_009.py: wilson_interval, two_proportion_test, benjamini_hochberg.

catan

depends on gamekit · gamekit[rl] via its own [rl] extra
  • agents/base.py re-exports Agent.
  • rl/env.py: CatanEnv is its own gym.Env, not a SingleAgentEnv. It uses advance_until_learner, coerce_to_legal, RewardFn and OpponentPool, and adds a composition buffer for its multi-part actions. It does not use ActionCodec.
  • rl/adapter.py: CatanTurnBasedGame satisfies TurnBasedGame structurally and imports nothing from gamekit.
  • experiments/benchmark.py: run_arm, rotate, seat_rng. critic_calibration.py: run_arm.
  • experiments/league_013.py: run_league, pairing_seeds, seat_rng.
  • server/bots.py: seat_rng. Experiments and rl/evaluate.py: wilson_interval, stamp, write_result.

Things the code says that the layering hides

  • Evaluation and RL are siblings, not layers. RL imports nothing from mc, benchmark or league, and evaluation never imports Agent.
  • seats.seat_rng is not called anywhere inside gamekit. It exists for games (catan uses it in its benchmark, league and server bots).
  • Neither consumer uses the MC fold (monte_carlo*, stopping, variance) on origin/main. The only mc names they import are wilson_interval, two_proportion_test and benjamini_hochberg.
  • mc.testing, mc.sample_size and mc.stopping import private names (_NORMAL, _z_score, _drawn) across modules.
  • TurnBasedGame is the only Protocol without @runtime_checkable.
